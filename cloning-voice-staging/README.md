# صوتك — Cloning Voice

موقع ستاتيك (GitHub Pages) بيعمل حاجتين:
1. **صوت بصوتك** من أي نص: العامية المصرية والإنجليزي أولاً، و22 لغة تانية بنفس الصوت، مع ترجمة مجانية.
2. **فيديو بمزامنة شفاه** من صورتك أو فيديو ليكي + الصوت.

الموقع نفسه مفيهوش ذكاء اصطناعي. الشغل التقيل بيعمله **محرك** بتشغّليه إنتِ مجاناً (على الكمبيوتر أو Google Colab)، أو ElevenLabs بمفتاحك.

```
index.html, app.js, style.css   الموقع (يتنشر على GitHub Pages)
engine/                         المحرك: Cairo-TTS + Chatterbox + NLLB + Wav2Lip خلف API صغير
start-engine.bat / .sh          تشغيل المحرك بدبل-كليك
studio/                         نسخة SaaS كاملة متعددة المستخدمين (للمرحلة الجاية)
```

## التشغيل
| الطريقة | التكلفة | السرعة | الملاحظات |
|---|---|---|---|
| Google Colab (T4 GPU) | مجاني | سريع | افتحي `engine/Sawtak_Engine_Colab.ipynb` من تبويب المحرك في الموقع. الجلسة بتقفل بعد خمول، وColab ممكن يقيّد الاستخدام المجاني من النوع ده. |
| الكمبيوتر | مجاني | GPU سريع، CPU أبطأ | `start-engine.bat` على ويندوز. أول مرة بتثبّت 10–20 دقيقة. |
| ElevenLabs | من رصيدك | الأسرع وأعلى جودة | حطي المفتاح في تبويب المحرك. مفيش مزامنة شفاه. |

في كل الحالات المحرك بيطبع **لينك توصيل**، تفتحيه والموقع يتوصل لوحده. اللينك فيه رمز سري، متشاركيهوش.

## النشر
Settings → Pages → Deploy from a branch → `main` / root. الموقع يبقى على `https://lioncoaching.github.io/cloning-voice/`.
