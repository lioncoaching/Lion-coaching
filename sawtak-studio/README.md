# صوتك ستوديو — Sawtak Studio

منصة SaaS جاهزة للبيع: **استنساخ الصوت → الكلام بأي لغة → فيديو ريلز بمزامنة شفاه → دبلجة فيديوهات قديمة**، مع موقع تسويقي، تطبيق ويب يتثبّت على الموبايل (PWA)، نظام حسابات وباقات وكريدت، ولوحة إدارة، وAPI للمطورين.

```
sawtak-studio/
├── backend/            FastAPI + SQLite — API + طابور تنفيذ + محركات قابلة للتبديل
│   └── app/engines/    tts/ (elevenlabs | cairo | mock)   lipsync/ (mux | wav2lip | latentsync)   translate.py (Claude)
├── frontend/           index.html (الموقع التسويقي)  app.html + app.js (التطبيق)  PWA (manifest + sw.js)
├── docs/               BUSINESS.md (خطة البيع والتسعير)  API.md (توثيق الـ API)
├── scripts/            dev.sh  install_local_engines.sh
├── docker-compose.yml  backend/Dockerfile  .env.example
```

## تشغيل في دقيقتين

```bash
cp .env.example .env        # حطي ELEVENLABS_API_KEY و SECRET_KEY و WHATSAPP_NUMBER
./scripts/dev.sh            # http://localhost:8000  (الموقع)  /app (التطبيق)  /docs (API)
```

أو بالدوكر:

```bash
docker compose up -d --build
```

أول حساب يتسجل بيبقى **أدمن** تلقائياً (أو الإيميل اللي في `ADMIN_EMAIL`).

## الرحلة اللي المستخدم بيعيشها

1. **أصواتي** → يرفع (أو يسجّل من المتصفح) 30 ثانية من صوته → استنساخ فوري. لو عنده صوت جاهز على ElevenLabs يربطه بزرار واحد.
2. **نص ← صوت** → يكتب السكريبت بالعامية، يختار "يطلع بلغة: English" → المنصة تترجم (Claude) وتتكلم بصوته.
3. **اعمل ريلز** → صورة/فيديو لوشه + السكريبت → فيديو عمودي 1080×1920 بصوته (بعلامة مائية في الباقة المجانية).
4. **دبلجة فيديو** → يرفع فيديو قديم ويختار لغة → نفس صوته باللغة الجديدة (ElevenLabs Dubbing).
5. **الباقة** → يختار باقة → تفتح رسالة واتساب جاهزة → يحوّل فودافون كاش/إنستاباي → الأدمن يفعّل من لوحة الإدارة.

## المحركات (بدّلي من `.env` من غير ما تلمسي كود)

| القدرة | الافتراضي (جاهز الآن) | البديل المجاني/المحلي |
|---|---|---|
| استنساخ + TTS متعدد اللغات | `TTS_ENGINE=elevenlabs` (29 لغة، أعلى جودة) | `cairo` — Cairo-TTS للعامية المصرية، يشتغل على CPU |
| مزامنة الشفاه | `LIPSYNC_ENGINE=mux` — صورة متحركة + صوت، بدون GPU | `wav2lip` (CPU) أو `latentsync` (GPU 8GB، أعلى جودة) |
| الترجمة | Claude (`ANTHROPIC_API_KEY`) | — |
| الدبلجة | ElevenLabs Dubbing | — |

`mock` محرك للتطوير بيطلع ملفات حقيقية من غير أي مفتاح — مفيد للتجربة والاختبار.

تثبيت المحركات المحلية: `./scripts/install_local_engines.sh` (محتاجة سيرفر بـ GPU للجودة العالية؛ Hetzner/RunPod/Vast.ai).

## الكريدت والباقات

التسعير كله في `backend/app/config.py` (`PLANS`) ومتغيرات `.env`:
- 1000 حرف ≈ 10 كريدت، ثانية فيديو ≈ 2 كريدت، استنساخ صوت = 50 كريدت، الترجمة بتضاعف تكلفة النص.
- الباقات: مجاني 200 / صانع محتوى 299ج (3000) / برو 899ج (12000) / وكالة 2999ج (50000).
- الفشل بيرجّع الكريدت تلقائياً. الرصيد بيتجدد كل 30 يوم.

## الـ API (لربط أي تطبيق موبايل أو أتمتة)

كل endpoint بيقبل `Authorization: Bearer <jwt>` أو `X-API-Key: <مفتاح المستخدم>`. التوثيق التفاعلي على `/docs`، والشرح في `docs/API.md`.

## الإنتاج

- حطي المنصة ورا Nginx/Caddy مع HTTPS (الميكروفون في المتصفح محتاج HTTPS).
- `SECRET_KEY` طويل وعشوائي. `ALLOW_SIGNUP=false` لو عايزة تسجيل بالدعوة.
- النسخ الاحتياطي = مجلد `data/` (قاعدة البيانات + ملفات المستخدمين).
- للتوسع: أكتر من `WORKER_THREADS`، أو انقلي الطابور لـ Redis/Celery وشغّلي عمال GPU منفصلين.

## الأخلاقيات والقانون

المنصة لاستنساخ **صوت المستخدم نفسه** أو صوت شخص أعطى إذناً كتابياً. ضيفي ذلك في شروط الاستخدام، وخلّي العلامة المائية في الباقة المجانية.
